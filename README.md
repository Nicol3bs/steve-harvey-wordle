# PYTHON WORDLE — PA2
A Programming Assignment for CIIC 3015

## 📌 Overview
Welcome to PA2!
This programming assignment challenges students to build a fully functional, terminal-based clone of the viral puzzle game Wordle. The goal of this assignment is to help students become comfortable working with strings, lists, dictionaries, nested loops, and modular functions, as well as introducing them to external libraries for terminal formatting.

## 🎮 Program Description
This program is a terminal recreation of Wordle. The computer selects a 5-letter English secret word, and the player has up to 6 attempts to guess it. After each guess, the game provides tile color feedback: Green (correct letter, correct spot), Yellow (correct letter, wrong spot), or Black (letter not in the word). An on-screen QWERTY keyboard also updates dynamically to track guessed letters.

Students will build the core algorithmic logic of the game from the ground up.
